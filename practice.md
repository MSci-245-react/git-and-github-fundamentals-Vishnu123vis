# What I Learned in Lecture 1

I learned about arrow functions and how they make functions shorter and easier to write in JavaScript. I also learned about `const` and `let`, and how they are used differently when creating variables.

## JavaScript REPL Snippet

```javascript
0.1 + 0.2
typeof null
[] == false
```

## Actual REPL Output

```
> 0.1 + 0.2
0.30000000000000004
> typeof null
'object'
> [] == false
true
> .exit
```

## Key Takeaways

- JavaScript has some weird type behavior.
- `typeof null` returns `'object'`, even though `null` is its own value.
- Decimal math can sometimes give unexpected results, like `0.1 + 0.2`.
